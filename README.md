# Operating Systems Practicals

A repository containing Operating Systems laboratory practical assignments, source code, and writeups.

## Contents

- **PR1**: Implementation of Address Book (using Shell Scripting & C Programming)
- **PR2**: Process Management (Fork, Wait, Sorting, Zombie & Orphan Processes)
- **PR3**: Thread Synchronization (Producer-Consumer Problem using Mutex / Semaphores)
- **PR4**: Thread Synchronization & Deadlock Handling (Reader-Writer Problem)
- **PR5**: Deadlock Avoidance using Banker's Algorithm
- **PR6**: Inter-Process Communication (IPC) using FIFOs (Named Pipes)
- **PR7**: Inter-Process Communication (IPC) using Pipes (Full-duplex Communication)
- **PR8**: Disk Scheduling Algorithms (SSTF, SCAN, and C-LOOK)
