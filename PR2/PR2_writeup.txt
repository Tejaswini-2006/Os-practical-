3. Theory
Process Management is an important function of an operating system that deals with the creation, execution and termination of processes.

1. fork() System Call
- The fork() system call creates a new process called the child process.
- The existing process is called the parent process.
- Both processes execute independently after creation.
- It returns 0 to the child process and the child's PID to the parent process.


2. wait() System Call
- The wait() system call is used by the parent process to wait for the termination of its child process.
- It collects the child's exit status.
- It helps in process synchronization and prevents zombie processes from remaining unreaped.


3. Zombie Process
- A Zombie process is a process that has completed execution but whose exit status has not yet been collected by its parent.
- It remains in the process table until the parent calls wait() or terminates.


4. Orphan Process
- An Orphan process is a child process whose parent terminates before the child completes execution.
- The operating system adopts the orphan process through init or another designated system process.
- The child continues its execution independently.
